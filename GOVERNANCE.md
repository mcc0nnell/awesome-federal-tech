# Governance

## Model

This repository operates under a lightweight benevolent-dictator / small
maintainer-team model. The goal is rapid, high-quality curation rather than
heavy process.

## Roles

- **Maintainers**: Responsible for final decisions on inclusion, exclusion,
  structure, and security review. Maintainers merge pull requests and manage
  releases of the data model.
- **Contributors**: Anyone who submits issues or pull requests. Contributions
  are welcome and will be reviewed against the published inclusion criteria.
- **Users**: Practitioners who consume the list. Feedback via issues is
  encouraged.

## Decision Making

- Day-to-day curation decisions are made by maintainers via pull-request review.
- Significant changes to taxonomy, inclusion criteria, or governance are
  discussed in issues before implementation.
- In case of disagreement, the lead maintainer has final decision rights.

## Conflict of Interest

Maintainers and contributors should disclose any material relationships with
projects they propose for inclusion (employment, funding, commercial interest).

## Changes to Governance

This document may be updated by pull request. Material changes will be
announced in a GitHub Discussion or release note.
