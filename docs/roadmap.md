# 90-Day Maintenance Roadmap

## Days 1–30 (Launch & Stabilization)

- Publish initial repository with seeded resources and automation.
- Open first set of GitHub issues for community feedback.
- Confirm all primary links resolve and validation workflows pass.
- Invite initial reviewers from federal practitioner networks.
- Add missing high-value official resources identified in early feedback.

## Days 31–60 (Expansion & Hardening)

- Complete first full pass of security notes for all executable tools.
- Expand accessibility and AI governance sections with additional primary
  sources.
- Improve persona “Start Here” guidance based on user input.
- Add any missing Platform One / Big Bang related public materials.
- Review and update FedRAMP/OSCAL entries for current official locations.

## Days 61–90 (Sustainability)

- Conduct first quarterly review of the entire catalog.
- Document contribution statistics and lessons learned.
- Evaluate whether a small advisory group is warranted.
- Publish a short “State of the Catalog” note.
- Plan next quarter priorities (deeper acquisition templates, additional cloud
  reference architectures, expanded training resources).

Ongoing: weekly automated checks, prompt response to broken links and security
disclosures.
